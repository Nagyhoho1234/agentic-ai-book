# Szójegyzék (Glosszárium)

Az alábbi táblázat a könyvben használt legfontosabb szakkifejezéseket gyűjti össze ábécérendben, angol és magyar megfelelőjükkel, rövid definícióval, valamint a részletesebb tárgyalás fejezetszámával.

| Angol | Magyar | Definíció | Fejezet |
|-------|--------|-----------|---------|
| A2A (Agent-to-Agent) | A2A (ágens-ágens protokoll) | A Google által javasolt nyílt protokoll, amely lehetővé teszi, hogy különböző AI ágensek egymással kommunikáljanak és feladatokat delegáljanak egymásnak, függetlenül attól, melyik keretrendszerben készültek. | 11. fejezet |
| Agent | Ágens | Olyan AI rendszer, amely nemcsak választ ad, hanem önállóan cselekszik: tervez, eszközöket használ, döntéseket hoz, és iteratívan halad egy cél felé. A chatbottól az különbözteti meg, hogy autonóm cselekvőképességgel rendelkezik. | 11. fejezet |
| API (Application Programming Interface) | API (alkalmazásprogramozási felület) | Szabványos „kapu", amelyen keresztül két szoftver egymással kommunikál. Amikor egy Python-szkript lekérdez egy AI modellt, azt egy API-n keresztül teszi. | 5. fejezet |
| Batch processing | Kötegelt feldolgozás | Nagy mennyiségű adat vagy feladat egyszerre, automatikusan történő feldolgozása, szemben az egyenkénti, kézi végrehajtással. | 7. fejezet |
| Chatbot | Chatbot (társalgórobot) | Szöveges párbeszédre képes AI program, amely kérdésekre válaszol. A legismertebb példák a ChatGPT, Claude és Gemini. Nem tévesztendő össze az ágenssel, amely önállóan cselekszik. | 2. fejezet |
| Chunk / Chunking | Chunk (szövegdarab) / darabolás | Hosszú dokumentumok kisebb, kezelhető szövegegységekre való felosztása. A RAG rendszerek a dokumentumokat chunkokra bontják, hogy a releváns részeket megtalálják és az AI-nak átadják. | 9. fejezet |
| Claude Code | Claude Code | Az Anthropic parancssori AI kódolási asszisztense, amely közvetlenül a terminálban működik. Fájlokat olvas, kódot ír és futtat, Git-műveleteteket végez -- a könyv egyik kiemelt eszköze. | 5. fejezet |
| Context window | Kontextusablak | Az a maximális szövegmennyiség (tokenben mérve), amelyet egy AI modell egyszerre „lát" és feldolgoz. Minél nagyobb a kontextusablak, annál hosszabb dokumentumokat vagy beszélgetéseket tud kezelni. | 2. fejezet |
| Copilot (GitHub Copilot) | Copilot | A GitHub és OpenAI közös AI kódolási asszisztense, amely a kódszerkesztőbe épülve valós időben javasol kódkiegészítéseket. | 5. fejezet |
| CrewAI | CrewAI | Python keretrendszer, amellyel több AI ágenst lehet csapatba szervezni. Minden ágensnek van szerepe, célja és eszközkészlete; a rendszer koordinálja az együttműködésüket. | 12. fejezet |
| CRISP-DM | CRISP-DM | Iparági szabvány adatelemzési módszertan hat lépésben (üzleti megértés, adatmegértés, adatelőkészítés, modellezés, kiértékelés, bevezetés). A vizuális programozási eszközök gyakran ezt a folyamatot követik. | 8. fejezet |
| Cursor | Cursor | AI-alapú kódszerkesztő (az VS Code forkja), amely beépített AI asszisztenssel segíti a kódírást, hibakeresést és refaktorálást. | 5. fejezet |
| Digital twin | Digitális iker | Egy valós fizikai rendszer (gép, épület, ökoszisztéma) virtuális, számítógépes másolata, amely valós idejű adatokkal szinkronizálódik. Lehetővé teszi „mi lenne, ha" szimulációk futtatását a valós rendszer megzavarása nélkül. | 10. fejezet |
| Embedding | Beágyazás | Szöveg, kép vagy más adat átalakítása számvektorrá (számlistává), amelyben a hasonló jelentésű elemek egymáshoz közeli pontokat kapnak. Ez teszi lehetővé a szemantikus keresést. | 9. fejezet |
| EU AI Act | EU AI rendelet (Mesterséges Intelligencia Jogszabály) | Az Európai Unió 2024-ben elfogadott, világelső átfogó AI-szabályozása, amely kockázati szintek szerint kategorizálja és szabályozza az AI rendszereket. | 16. fejezet |
| Fine-tuning | Finomhangolás | Egy már betanított AI modell további edzése speciális adatokon, hogy egy adott szakterületen vagy feladattípusban jobban teljesítsen. Költséges és szakértelmet igényel; a RAG gyakran olcsóbb alternatíva. | 9. fejezet |
| GDPR (General Data Protection Regulation) | GDPR (Általános Adatvédelmi Rendelet) | Az EU adatvédelmi rendelete, amely szabályozza a személyes adatok gyűjtését, tárolását és feldolgozását. AI használatakor különösen fontos, mert az adatok felhőszolgáltatásokba kerülhetnek. | 4. fejezet |
| Git | Git | Verziókezelő rendszer, amely rögzíti a fájlok minden változtatását, lehetővé téve a korábbi állapotokhoz való visszatérést. A kutatási kód és szkriptek biztonságos kezelésének alapeszköze. | 5. fejezet |
| Gradio | Gradio | Python könyvtár, amellyel néhány sor kóddal webes felületet (GUI-t) lehet készíteni AI modellekhez vagy adatelemzésekhez. A kutató megoszthatja az eredményeit anélkül, hogy a felhasználónak programoznia kellene. | 13. fejezet |
| Hallucination | Hallucináció | Amikor az AI modell magabiztosan állít valamit, ami nem igaz: kitalált hivatkozások, nem létező adatok, hamis tényállítások. A tudományos munkában ez az egyik legveszélyesebb AI-kockázat. | 2. fejezet |
| Hyperparameter | Hiperparaméter | Olyan beállítási érték, amelyet nem a modell tanul meg az adatokból, hanem a felhasználó ad meg a tanítás előtt (pl. tanulási ráta, rétegszám). Az optimális értékek megtalálása a hiperparaméter-hangolás. | 6. fejezet |
| Jupyter notebook | Jupyter notebook | Interaktív, böngészőalapú programozási környezet, amelyben kód, szöveg, képletek és ábrák egyetlen dokumentumban keverednek. A tudományos Python-munka egyik leggyakoribb felülete. | 5. fejezet |
| KNIME | KNIME | Nyílt forráskódú, vizuális adatelemző platform, amelyben a feldolgozási lépéseket dobozok (node-ok) összekötésével lehet megadni, programozás nélkül. | 8. fejezet |
| LangChain | LangChain | Python/JavaScript keretrendszer LLM-alapú alkalmazások építéséhez, amely szabványos modulokat kínál a promptkezeléshez, memóriához, eszközhasználathoz és láncolt műveletekhez. | 9. fejezet |
| LangFlow | LangFlow | A LangChain vizuális, drag-and-drop felülete, amelyben LLM-alapú munkafolyamatokat lehet összeállítani kódírás nélkül. | 8. fejezet |
| LangGraph | LangGraph | A LangChain kiterjesztése, amely gráfalapú (ciklikus) munkafolyamatok létrehozását teszi lehetővé AI ágensek számára, ahol az ágens visszaléphet, újragondolhat és alternatív utakat választhat. | 12. fejezet |
| LLM (Large Language Model) | Nagy nyelvi modell | Több milliárd paraméterből álló mesterséges intelligencia modell, amelyet hatalmas szövegmennyiségen tanítottak. Szöveget generál, kérdésekre válaszol, kódot ír és fordít. Példák: GPT-4, Claude, Gemini. | 1. fejezet |
| MCP (Model Context Protocol) | MCP (Modellkontextus-protokoll) | Az Anthropic által kidolgozott nyílt szabvány, amelyen keresztül AI modellek biztonságosan csatlakozhatnak külső adatforrásokhoz és eszközökhöz (adatbázisok, fájlrendszerek, API-k). Az AI ágensek „érzékszerveit" biztosítja. | 11. fejezet |
| Monte Carlo (simulation) | Monte Carlo-szimuláció | Számítási módszer, amelyben véletlenszerű mintavétellel, sok ezerszer megismételve egy számítást becsüljük meg egy összetett rendszer viselkedését vagy egy eredmény bizonytalanságát. | 6. fejezet |
| Multi-agent system | Többágenses rendszer | Olyan architektúra, amelyben több, specializált AI ágens dolgozik együtt egy komplex feladaton -- például az egyik keres, a másik elemez, a harmadik ír. Az ágensek egymás eredményeire építenek. | 11. fejezet |
| n8n | n8n | Nyílt forráskódú, vizuális munkafolyamat-automatizáló platform, amelyben különböző szolgáltatásokat (e-mail, adatbázis, AI, fájlrendszer) lehet összekötni kódolás nélkül. | 8. fejezet |
| Neural network | Neurális hálózat | Az emberi agy működését nagyon leegyszerűsítve utánzó számítási modell, amelyben „neuronok" rétegei dolgozzák fel az adatokat. A modern AI (beleértve az LLM-eket) neurális hálózatokra épül. | 1. fejezet |
| Node-RED | Node-RED | Böngészőalapú, vizuális programozási eszköz, amely eredetileg IoT-alkalmazásokhoz készült, de tudományos adatfolyamatok és automatizálások építésére is kiválóan alkalmas. | 8. fejezet |
| ODE / PDE | ODE (közönséges differenciálegyenlet) / PDE (parciális differenciálegyenlet) | A természettudományok matematikai alapnyelvei. Az ODE egyetlen változó szerinti változást ír le (pl. populációnövekedés az időben), a PDE több változó szerintit (pl. hőterjedés térben és időben). Az AI segíthet ezek numerikus megoldásában. | 6. fejezet |
| Optuna | Optuna | Python könyvtár hiperparaméterek automatikus optimalizálására. Intelligens keresési stratégiákkal hatékonyabban találja meg a legjobb beállításokat, mint a hagyományos rácskereső módszerek. | 6. fejezet |
| Orange | Orange | Vizuális adatbányászati és gépi tanulási eszköz, amelyben widgetek (dobozok) összekötésével lehet elemzési folyamatokat összeállítani, teljesen programozás nélkül. Különösen népszerű oktatási környezetben. | 4. fejezet |
| PINNs (Physics-Informed Neural Networks) | PINNs (fizikainformált neurális hálózatok) | Speciális neurális hálózatok, amelyekbe a fizikai törvényeket (differenciálegyenleteket) közvetlenül beépítik a tanítási folyamatba, így az eredmény nemcsak az adatokra illeszkedik, hanem a fizikai szabályoknak is megfelel. | 6. fejezet |
| Pipeline | Pipeline (adatcsővezeték, feldolgozási lánc) | Egymás után kapcsolt feldolgozási lépések sorozata, amelyben az egyik lépés kimenete a következő bemenete. Automatizálja az ismétlődő adatfeldolgozási munkafolyamatokat. | 7. fejezet |
| Post-plagiarism | Posztplágium | Az AI korszak új etikai kihívása: amikor a szöveget nem másolják, hanem AI-val generálják, így a hagyományos plágiumellenőrzők nem jelzik, mégis felmerül a szellemi eredetiség kérdése. | 16. fejezet |
| Prompt | Prompt (utasítás, kérdés) | Az a szöveges bemenet (kérdés, utasítás, leírás), amelyet a felhasználó az AI modellnek ad. A prompt minősége alapvetően meghatározza a válasz minőségét. | 2. fejezet |
| Prompt engineering | Prompttervezés (prompt engineering) | A promptok tudatos megszerkesztésének művészete és módszertana annak érdekében, hogy az AI a lehető legjobb, legpontosabb és leghasználhatóbb választ adja. | 2. fejezet |
| PySR | PySR | Python könyvtár szimbolikus regresszióhoz: az adatokból nem fekete doboz modellt, hanem olvasható matematikai képleteket állít elő, amelyeket a kutató értelmezni és publikálni tud. | 6. fejezet |
| Python | Python | Általános célú programozási nyelv, amely egyszerű szintaxisának és gazdag tudományos könyvtárainak köszönhetően a tudományos számítástechnika és az AI legnépszerűbb nyelve. | 5. fejezet |
| RAG (Retrieval-Augmented Generation) | RAG (kereséssel kiegészített generálás) | Technika, amelyben az AI modell a válaszadás előtt releváns dokumentumokat keres ki egy tudásbázisból, és azok alapján válaszol. Így a modell a saját kutatási anyagainkat is felhasználhatja, anélkül hogy újratanítanánk. | 9. fejezet |
| ReAct (Reasoning + Acting) | ReAct (gondolkodás + cselekvés) | AI ágensek működési mintázata, amelyben a modell felváltva gondolkodik (elemzi a helyzetet) és cselekszik (eszközt használ), majd megfigyeli az eredményt, és ez alapján folytatja. Ez teszi lehetővé az összetett, többlépéses feladatmegoldást. | 11. fejezet |
| RLHF (Reinforcement Learning from Human Feedback) | RLHF (megerősítéses tanulás emberi visszajelzésből) | Az LLM-ek tanításának utolsó fázisa, amelyben emberi értékelők rangsorolják a modell válaszait, és a modellt jutalmazzák a jobb válaszokért. Ez teszi az AI-t segítőkésszé, biztonságossá és kulturálttá. | 16. fejezet |
| SARPS (Scientific AI Reproducibility and Provenance Standards) | SARPS (Tudományos AI Reprodukálhatósági és Származási Szabványok) | Keretrendszer a tudományos AI-használat átlátható dokumentálására: rögzíti, milyen modellt, promptot és beállításokat használtak, biztosítva a kutatás reprodukálhatóságát. | 15. fejezet |
| scikit-learn | scikit-learn | A legnépszerűbb Python gépi tanulási könyvtár, amely egyszerű felületet kínál osztályozáshoz, regresszióhoz, klaszterezéshez és adatelőfeldolgozáshoz. Ideális kiindulópont a gépi tanuláshoz. | 4. fejezet |
| Streamlit | Streamlit | Python könyvtár, amellyel gyorsan lehet interaktív webes adatvizualizációs alkalmazásokat és dashboardokat készíteni. Különösen népszerű kutatási prototípusokhoz. | 13. fejezet |
| SymPy | SymPy | Python könyvtár szimbolikus matematikához: képleteket kezel, egyenleteket old meg, derivál és integrál -- nem numerikusan, hanem zárt alakban, ahogy azt kézzel is tennénk. | 6. fejezet |
| System prompt | Rendszerprompt | A modellnek adott rejtett háttérutasítás, amely meghatározza a viselkedését, hangnemét, szerepét és korlátait az egész beszélgetés során. A felhasználó általában nem látja, de döntően befolyásolja a válaszokat. | 2. fejezet |
| Temperature | Hőmérséklet (temperature) | Az LLM generálási paramétere (jellemzően 0 és 2 között), amely a válaszok véletlenszerűségét szabályozza. Alacsony érték = kiszámítható, determinisztikus válasz; magas érték = kreatívabb, változatosabb, de kockázatosabb kimenet. | 2. fejezet |
| Token | Token | Az LLM-ek szövegfeldolgozásának alapegysége: egy szó, szórész vagy írásjel. Egy magyar szó általában 1--3 token. A tokenszám határozza meg a kontextusablak méretét és az API-költségeket. | 2. fejezet |
| Top-p (nucleus sampling) | Top-p (magmintavételezés) | Generálási paraméter, amely megszabja, hogy a modell a következő token kiválasztásakor a legvalószínűbb tokenek mekkora hányadából válasszon. Top-p = 0,1 esetén csak a legvalószínűbb 10%-ból; top-p = 1,0 esetén az összes lehetőségből. | 2. fejezet |
| Vector store | Vektortár (vektor-adatbázis) | Speciális adatbázis, amely szövegek beágyazásait (numerikus vektorait) tárolja, és villámgyors hasonlósági keresést tesz lehetővé. A RAG rendszerek központi eleme. | 9. fejezet |
| Virtual environment | Virtuális környezet | Elszigetelt Python-környezet, amelyben egy projekt függőségei (könyvtárai) a rendszer többi részétől függetlenül telepíthetők. Megakadályozza, hogy különböző projektek könyvtárai ütközzenek egymással. | 5. fejezet |

---

> **Megjegyzés:** A szójegyzék a könyv első kiadásának fogalmait tartalmazza. Az AI terület rendkívül gyorsan fejlődik; az újabb kiadások további fogalmakkal bővülhetnek.
