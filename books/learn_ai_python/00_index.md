# Learn AI-Assisted Python Programming with GitHub Copilot

**Authors:** Leo Porter, Daniel Zingaro
**Publisher:** Manning Publications, 2023
**ISBN:** 9781633437784

## Book Overview

This book teaches Python programming from scratch using AI coding assistants, primarily GitHub Copilot. It is aimed at complete beginners who have never programmed before, demonstrating that the traditional approach of memorizing syntax can be replaced by learning to communicate effectively with AI tools. The authors -- both computer science professors -- argue that AI assistants fundamentally change how programming should be taught and practiced.

## Core Thesis

Programming with AI assistants shifts the programmer's role from writing code to:
1. Decomposing problems into small, well-defined functions
2. Writing precise natural-language prompts (docstrings)
3. Reading and verifying AI-generated code
4. Testing to ensure correctness
5. Debugging when things go wrong

## Key Themes Across All Chapters

- **Prompt engineering through docstrings:** The quality of the AI's output depends directly on the clarity and specificity of your function descriptions
- **Top-down design:** Break large problems into smaller sub-problems, each becoming its own function
- **Code reading over code writing:** You must understand what the AI produces, even if you did not write it yourself
- **Testing as a first-class skill:** AI-generated code is not guaranteed correct; systematic testing catches errors
- **Iterative conversation with AI:** When Copilot gives wrong code, refine your prompt rather than giving up
- **The human remains in charge:** The programmer decides what to build, how to decompose it, and whether the result is correct
