## Table of Contents

- [Chapter 1: Getting Started with n8n](ch01_getting_started_with_n8n.md) - Installation, setup options (Cloud/Docker/Local), first login, interface navigation, and first demo workflow.

- [Chapter 2: Understanding the n8n Universe](ch02_understanding_the_n8n_universe.md) - Core concepts: workflows, nodes, executions. Node types (trigger, action, core, AI). Building single and multi-agent systems. Triggers, JSON data flow, credentials.

- [Chapter 3: Your First Real Automation](ch03_your_first_real_automation.md) - Hands-on project: Daily Weather Alert System using Schedule Trigger, OpenWeatherMap API, data formatting, conditional logic, and notification delivery.

- [Chapter 4: Your AI Agent Journey](ch04_your_ai_agent_journey.md) - LLM vs. Agent distinction, agent architectures (single, sequential, parallel, loop-based), MCP servers, human-in-the-loop, RAG, prompting principles, best practices, and real-world templates.

- [Chapter 5: Flow Control, Data Handling and Transformation](ch05_flow_control_data_handling.md) - Import/export workflows, flow logic (splitting, merging, looping, waiting), conditional logic (IF/Switch), sub-workflows, triggers (manual, schedule, webhook, app-specific), JSON, expressions, advanced data manipulation, Code node.

- [Chapter 6: Integrations and Ecosystem](ch06_integrations_and_ecosystem.md) - Popular integrations (Google Workspace, social media, productivity, comms), OAuth 2.0 and API key authentication, project: Social Media Content Pipeline.

- [Chapter 7: Communication Workflows](ch07_communication_workflows.md) - Email automation (AI sorting, auto-responses, email-to-task), Email Command Center, social media autopilot, analytics dashboards, Personal Brand Management System.

- [Chapter 8: Document and Task Management](ch08_document_and_task_management.md) - File automation with Mistral AI, document processing (OCR), PDF generation, backup systems, invoice processing, task/project management automation, calendar integration.

- [Chapter 9: Business and Personal Use Cases](ch09_business_and_personal_use_cases.md) - CRM automation, sales pipeline, marketing campaigns, financial reporting, personal life automation (smart home, finance, health, learning), error handling and bulletproof workflows.

- [Chapter 10: Workflow Management and Scaling](ch10_workflow_management_and_scaling.md) - Naming conventions, documentation, version control, performance optimization, API rate limits, vertical vs. horizontal scaling, queue mode, Docker Compose for production.

- [Chapter 11: Security and Troubleshooting](ch11_security_and_troubleshooting.md) - Securing installations, secrets management, HTTPS/reverse proxy, backup/disaster recovery, troubleshooting methodology, debugging step-by-step, reading logs and error messages, community resources.

- [Chapter 12: Customization and Future Directions](ch12_customization_and_future_directions.md) - Advanced JavaScript in Code nodes, building custom nodes (Weather Alert example), sharing nodes via npm, automation mindset, ROI analysis, career opportunities, AI agent future trends.
