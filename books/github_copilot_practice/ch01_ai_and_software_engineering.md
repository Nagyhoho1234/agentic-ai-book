# Chapter 1: AI and Software Engineering

## Summary

This short introductory chapter sets the stage by surveying the current state of AI in software engineering. Wienholt argues that while AI tools like GitHub Copilot represent a genuine paradigm shift, the software industry has a long history of overhyping new technologies. He draws parallels to previous "revolutions" (BizTalk, Power Apps, low-code platforms) that promised to eliminate the need for developers but ultimately failed to deliver on those promises.

The chapter establishes the book's central thesis: AI coding tools are a powerful productivity enhancement for experienced developers, not a replacement for software engineering expertise. The author introduces GitHub Copilot as the leading AI coding tool and positions it within the broader ecosystem of AI-assisted development, including ChatGPT, Claude, and Gemini models.

Wienholt emphasizes that the book targets practical enterprise adoption rather than theoretical discussion, covering the full software development lifecycle from architecture through deployment and organizational change management.

## Key AI Coding Techniques

- AI-assisted coding is positioned as the latest in a long line of productivity tools, from IDEs to frameworks
- GitHub Copilot is identified as the dominant tool due to its deep IDE integration
- Multiple LLM backends (GPT, Claude, Gemini) can be used through Copilot's interface
- The distinction between code generation (new code) and code completion (inline suggestions) is introduced

## Practical Takeaways for Scientists

- AI coding tools are genuinely useful for accelerating development, especially for repetitive or boilerplate tasks
- Do not expect AI to replace domain expertise -- it augments what you already know
- The technology is evolving rapidly; the specific tool matters less than learning the general workflow of AI-assisted development
- Previous technology "revolutions" that were supposed to eliminate coding (low-code, BizTalk, Power Apps) all failed; AI coding tools are more promising but still require skilled humans
