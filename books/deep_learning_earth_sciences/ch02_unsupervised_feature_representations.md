# Chapter 2: Learning Unsupervised Feature Representations of Remote Sensing Data with Sparse Convolutional Networks

**Authors:** Jose E. Adsuara, Manuel Campos-Taberner, Javier Garcia-Haro, Carlo Gatta, Adriana Romero, and Gustau Camps-Valls

## Summary

This chapter addresses the fundamental problem of learning meaningful feature representations from remote sensing data without labeled training samples. The authors introduce a methodology based on sparse convolutional neural networks trained in an unsupervised manner using the EPLS (Enforcing Population and Lifetime Sparsity) algorithm. The approach generates "pseudo-labels" by imposing sparsity constraints, enabling standard CNNs to be trained layer-wise without supervision. The method is demonstrated on hyperspectral image classification and multisensor (RGB + LiDAR) image fusion tasks.

The key insight is that natural data -- especially data generated by physical processes -- lives in lower-dimensional subspaces and can be represented sparsely. This motivates using sparsity as the guiding criterion for unsupervised feature learning, rather than requiring labeled data.

## Key Concepts and Methods

### Dimensionality Reduction Context
- Traditional methods: PCA (linear, assumes orthogonality), kPCA (kernel-based nonlinear)
- Manifold learning: LLE, LTSA, Laplacian eigenmaps (local methods); ISOMAP (global method)
- Autoencoders: Neural networks that learn compressed representations through reconstruction
- **Problem**: Autoencoders require careful tuning of hyperparameters; choosing an objective criterion for unsupervised learning is inherently challenging

### Sparsity as a Guiding Criterion
- **Population sparsity**: Only small subsets of outputs are active at the same time
- **Lifetime sparsity**: Each output activates rarely but with high activation when it does
- Most existing methods (RBM, SAE, Sparse Coding, PSD, OMP-k) optimize for one type of sparsity, not both
- The EPLS algorithm enforces both population AND lifetime sparsity simultaneously

### The EPLS Algorithm
- Meta-parameter free, off-the-shelf algorithm for unsupervised sparse feature learning
- Iteratively builds sparse targets from CNN layer outputs, then optimizes the layer to match those targets
- Optimization: L2-norm minimization between layer output and sparse target, using SGD with adaptive learning rates
- Training is done layer-wise (greedy), with each layer learning increasingly abstract features

### Applications
1. **Hyperspectral Image Classification**: AVIRIS Indiana's Indian Pines dataset (614x2166 pixels, 220 spectral bands, 38 classes). Deep (6-layer) networks using only 5% samples/class outperformed single-layer networks using 30% samples/class. Best results with 200 features per layer and 5x5 receptive fields.
2. **Multisensor Image Fusion**: RGB + LiDAR data from 2015 IEEE GRSS Data Fusion Contest. The learned bases for RGB captured edges, colors, and corners; LiDAR bases captured height variations; combined RGB+LiDAR bases inherited properties of both modalities. ISOMAP visualization confirmed complementarity of the fused representations.

## Practical Takeaways for Scientists

1. **Sparse representations are more compact and interpretable** than dense ones, and deeper networks produce sparser (better) features.
2. **Unsupervised pretraining with EPLS** can be applied to any CNN architecture -- useful when labeled data is scarce (common in RS).
3. **Multimodal fusion** (e.g., optical + LiDAR) produces representations that combine the strengths of each modality, but the fused representation is less sparse due to complementary information content.
4. **Deeper is better**: A 6-layer unsupervised network trained on 5% of labeled samples outperforms a single-layer network trained on 30%.
5. **Contrastive learning** (CPC, SimCLR) is identified as a promising future direction for unsupervised RS feature learning.
