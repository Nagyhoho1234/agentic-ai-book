# Chapter 15: Deep Learning and the Weather Forecasting Problem: Precipitation Nowcasting

**Authors:** Zhihan Gao, Xingjian Shi, Hao Wang, Dit-Yan Yeung, Wang-chun Woo, and Wai-Kin Wong

## Summary

This chapter provides a comprehensive review of deep learning methods for precipitation nowcasting -- forecasting rainfall 0-6 hours ahead at high spatiotemporal resolution. The problem is formulated as spatiotemporal sequence forecasting: given a sequence of radar echo maps, predict the next sequence of maps. The chapter systematically covers learning strategies (IME, DME, Scheduled Sampling), FNN-based models (U-Net, DozhdyaNet), and RNN-based models (ConvLSTM, PredRNN, MIM, TrajGRU), culminating in the HKO-7 benchmark for standardized comparison.

## Key Concepts and Methods

### Problem Formulation
- Input: sequence of J past radar echo maps on an MxN grid with D measurements per cell
- Output: prediction of L future radar echo maps
- Spatiotemporal sequence forecasting: argmax p(X_{t+1:t+L} | X_{t-J+1:t})
- Typical setup: 6-minute interval radar data, predict 0-60 frames (0-6 hours) ahead

### Learning Strategies for Multi-step Forecasting

**Iterative Multi-step Estimation (IME):**
- Train a single one-step-ahead model, apply recursively
- Advantage: simple to train, arbitrary horizon length
- Disadvantage: error accumulation over time steps (teacher forcing discrepancy)

**Direct Multi-step Estimation (DME):**
- Train separate model for each forecast horizon
- More accurate but more expensive (L models needed)
- Directly optimizes multi-step error

**Scheduled Sampling (SS):**
- Bridge between IME and DME (curriculum learning)
- Gradually transitions from ground-truth inputs to model-generated inputs during training
- Probability epsilon_k of using ground-truth decays during training

### FNN-based Models

**DozhdyaNet** (Ayzel et al., 2019): All-convolutional network; concatenates temporal frames as channels

**U-Net** (Agrawal et al., 2019): Encoder-decoder with skip connections; down/up-sampling; QPE data from MRMS; outperforms optical flow methods

**Dynamic Convolution** (Klein et al., 2015): Input-dependent filters generated by sub-network B, applied to features from sub-network A

### RNN-based Models

**ConvLSTM** (Xingjian et al., 2015): Foundational architecture
- Replaces matrix multiplications in FC-LSTM with convolutions
- All inputs, states, and gates are 3D tensors with spatial dimensions
- Each cell determines its future state from local spatial neighbors
- Encoder-forecaster (EF) architecture with stacked ConvLSTM layers
- Outperforms optical flow (ROVER) on Hong Kong radar data
- Key finding: state-state convolution kernel size >1 is essential

**ConvLSTM with Star-shaped Bridge** (Cao et al., 2019): Global state via 1x1 convolution across all layers; residual connections to all layers at t+1; with Group Normalization

**PredRNN / ST-LSTM** (Wang et al., 2017d): External spatiotemporal memory cell M updated in zigzag pattern across layers; captures cross-layer dependencies that stacked ConvLSTM misses

**Memory In Memory (MIM)** (Wang et al., 2019b): Cascaded non-stationary module (MIM-N) and stationary module (MIM-S) replace forget gate; explicitly models non-stationary dynamics via differencing between consecutive hidden states

**Trajectory GRU (TrajGRU)** (Shi et al., 2017): Learns location-variant connection structures for state transitions; sub-network generates flow fields (U,V) determining which neighbors to aggregate; more efficient than ConvLSTM (O(L x C_h^2) vs O(K^2 x C_h^2) parameters)

### HKO-7 Benchmark
- First systematic benchmark for precipitation nowcasting
- Hong Kong Observatory radar data: 97-day rainy season
- 480x480 grid, 6-minute intervals, predict next 20 frames (2 hours)
- Evaluation metrics: CSI, HSS, B-MSE, B-MAE at multiple rainfall thresholds
- ConvLSTM with scheduled sampling achieves best balanced performance
- TrajGRU excels at capturing location-variant motion patterns

## Practical Takeaways for Scientists

1. **ConvLSTM is the baseline architecture** for precipitation nowcasting -- it jointly captures spatial and temporal patterns.
2. **Scheduled Sampling** is recommended over pure IME or DME for multi-step forecasting.
3. **TrajGRU** is more parameter-efficient than ConvLSTM and better handles location-variant dynamics.
4. **HKO-7 benchmark** (github.com/sxjscience/HKO-7) provides standardized evaluation for fair comparison.
5. **Error accumulation** is the fundamental challenge -- all models degrade with forecast horizon, producing increasingly blurry predictions.
6. **Optical flow methods remain competitive** for very short lead times (6-12 minutes).
