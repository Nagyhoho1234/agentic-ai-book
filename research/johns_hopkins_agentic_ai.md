# Johns Hopkins University Agentic AI Certificate Program

## Comprehensive Research Summary

**Last updated:** March 29, 2026

---

## 1. Program Overview

The **Certificate Program in Agentic AI** is a 16-week online professional certificate offered by Johns Hopkins University's Whiting School of Engineering, delivered in collaboration with Great Learning (a global professional learning company operating in 14+ countries). The program teaches professionals to design AI agents that perceive, reason, and act autonomously.

- **Duration:** 16 weeks
- **Format:** Fully online (recorded lectures + live sessions)
- **Cost:** $3,000 USD (payment plans available; periodic $100-$150 fee waivers offered)
- **Credential:** Certificate of Completion from Johns Hopkins University + 11 Continuing Education Units (CEUs)
- **Deliverable:** Shareable e-Portfolio of practical work
- **Contact:** +1 410 632 6604

**Key distinction:** Unlike programs that treat agentic AI as one module within a broader AI curriculum, JHU structures the **entire** 16-week certification around agentic architecture, using the OODA framework (Observe, Orient, Decide, Act) as the foundational paradigm throughout.

**Program URL:** https://online.lifelonglearning.jhu.edu/jhu-certificate-program-agentic-ai

---

## 2. Target Audience

The program is designed for:

- **STEM professionals** with programming or mathematics backgrounds
- **Data scientists and AI/ML engineers** looking to specialize in agentic systems
- **Technical and product managers** overseeing AI implementation
- **Software engineers** transitioning into AI agent development
- **Aspiring professionals** (with Python pre-work module support)

A STEM background with some prior familiarity with a programming language or technical subject matter in mathematics/data is recommended but not strictly required, as the pre-work module covers Python fundamentals.

## 3. Detailed Curriculum Breakdown

### Pre-Work Module (Before Week 1)
- Landscape of AI, Generative AI, and Agentic AI (orientation)
- Python basics: fundamentals, object-oriented programming, key data science libraries
- Math and data science foundations calibration
- Students are encouraged to use LLMs (e.g., ChatGPT) for coding assistance during pre-work

### Module 1: Prompt Engineering Foundations (Weeks 1-4)
- LLM mechanics: how large language models work under the hood
- Prompt optimization strategies:
  - Zero-shot prompting
  - Few-shot prompting
  - Chain-of-Thought (CoT) reasoning
  - Tree-of-Thought reasoning
- Model parameters: temperature, top_p, frequency penalties
- DSPy framework for declarative prompting
- Retrieval-Augmented Generation (RAG) with Chroma DB
- Hugging Face and LangChain integration
- **Project 1:** AI agent for financial analysis and investment advice (combining prompt engineering, semantic search, and live data integration)

### Module 2: Introduction to Agentic AI Design (Weeks 5-8)
- Agent definitions, environmental interactions, and autonomy levels
- Goal complexity and differences between traditional AI and agent-based systems
- Agent architecture paradigms:
  - **Symbolic formulation** for predictable, auditable AI systems
  - **BDI (Belief-Desire-Intention)** models
  - **LLM-based agents** and integration patterns
- Ethics, safety, and responsible AI fundamentals
- Planning and reasoning mechanisms:
  - Classical planning
  - ReAct framework
  - Chain-of-Thought in agent contexts

### Module 3: Designing and Building Agentic Systems (Weeks 9-12)
- Reinforcement learning fundamentals and application to agents
- Multi-agent systems (MAS) coordination and collaboration
- Embodied AI concepts
- LLM integration with agentic frameworks
- Model Context Protocol (MCP) for agent communication
- Frameworks: LangChain, AutoGen
- Case studies of real-world agentic deployments
- **Project 2:** Autonomous Decision Agents (perception, planning, adaptive behavior)

### Module 4: Advanced Agentic AI (Weeks 13-16)
- AI alignment and the Alignment Problem in practice
- Preventing agent hallucinations
- Managing multi-agent loops and controlling API costs
- Human-agent collaboration and interaction design
- Safeguards, monitoring, and ethical deployment considerations
- Future of AI: embodiment and next-generation agents
- **Culminating Project:** Intelligent customer support chatbot integrating all learned skills
- **Project 3:** Collaborative multi-agent systems using LangChain and AutoGen

### Three Major Project Milestones (Progressive)
1. **Workflow Automation Agents** -- error handling and tool-use verification
2. **Autonomous Decision Agents** -- perception, planning, and adaptive behavior
3. **Collaborative Multi-Agent Systems** -- coordination frameworks

Additional projects mentioned in program materials:
- Smart Data Processing Agent (automates workflow tasks)
- Automated Research Agent (information retrieval capabilities)

## 4. Learning Format and Delivery

- **Recorded video lectures:** Faculty-led, released weekly by JHU Whiting School of Engineering faculty
- **Monthly live masterclasses:** 4 sessions led by JHU faculty exploring advanced themes
- **Live mentored sessions:** 15 sessions with industry experts for personalized mentorship
- **AI-assisted learning tools:** Integrated throughout
- **Jupyter notebooks:** Hands-on coding exercises
- **Graded quizzes:** Weekly assessments
- **Discussion forums:** Peer learning and academic support
- **Dedicated Program Manager:** Individual support
- **Peer learning groups:** Cohort-based community

**Weekly time commitment:** 3-5 hours for Python-proficient learners; 5-6 hours typical; 10+ hours if learning Python simultaneously.

**Important note:** Content unlocks weekly (not self-paced); students cannot accelerate through modules ahead of schedule.

## 6. Prerequisites and Admission

### Recommended Background
- STEM background with familiarity in a programming language
- Technical subject matter knowledge in mathematics or data
- Intermediate Python proficiency (pre-work module available for those needing it)

### Admission Process
1. Complete a simple online application form
2. A panel from Great Learning reviews the application for program fit
3. Receive an offer for a seat in the upcoming cohort
4. Admissions close once the required number of participants enroll

**Current application deadline:** March 31, 2026 (rolling cohorts)

### What This Is NOT
- This is a **non-degree certificate program** (Certificate of Completion, not academic credit)
- Does **not** confer JHU alumni status
- CEUs are continuing education units, not graduate credits

## 10. The Engineering for Professionals (EP) Division Context

Johns Hopkins Engineering for Professionals (EP) is the part-time, online division of the Whiting School of Engineering. It is distinct from (but complementary to) the Great Learning certificate programs.

### EP Master's in Artificial Intelligence
- **Degree:** Master of Science in Artificial Intelligence
- **Structure:** 10 graduate-level courses (30 credits) within 5 years
- **Core:** 2 core courses (6 credits) + 3 required courses (9 credits) + 5 electives (15 credits)
- **Topics:** Machine learning, data science, NLP, robotics, neural networks, computer intelligence, expert systems
- **Format:** Short video lectures + weekly Zoom sessions with instructors

### EP Graduate Certificate in AI
- 4 graduate-level courses within 5 years
- Courses can count toward the full master's degree if student later enrolls
- This is a **credit-bearing** academic credential (unlike the Great Learning certificates)

### EP Course: Introduction to Agentic AI (EN.705.625)
- **Credits:** 3 graduate credits
- **Launched:** Fall 2025
- **Prerequisite:** EN.625.638/EN.605.647 Neural Networks (or equivalent experience)
- **Content:** Decision trees, utility theory, Markov decision processes, game theory, standalone and multi-agent system design, generative agents powered by large language and vision models
- **Follow-on:** 700-level advanced course planned for Spring 2026
- **URL:** https://ep.jhu.edu/courses/705625-introduction-to-agentic-ai/

### Key Distinction: Certificate Program vs. EP Courses
| Feature | Great Learning Certificate | EP Graduate Course |
|---------|---------------------------|-------------------|
| Credits | CEUs (non-credit) | 3 graduate credits |
| Duration | 16 weeks (full program) | 1 semester (single course) |
| Cost | $3,000 (full program) | Per-credit JHU tuition |
| Prerequisite | STEM background | Neural Networks course |
| Depth | Broad survey of agentic AI | Deep academic treatment |
| Credential | Certificate of Completion | Counts toward MS degree |

## 12. What Makes This the Closest Curriculum to Teaching Agentic AI for Professionals

The JHU Agentic AI Certificate stands out among professional education options for several reasons:

1. **Dedicated agentic focus:** The entire 16-week program is built around agentic AI rather than treating it as one module within a broader AI/ML curriculum. Most competing programs (UT Austin, IBM, Vanderbilt) cover agents as a component.

2. **Architectural depth:** Covers three distinct agent paradigms -- symbolic, BDI, and LLM-based -- providing theoretical grounding that most bootcamp-style programs skip entirely.

3. **OODA framework as pedagogy:** Uses the Observe-Orient-Decide-Act loop as a consistent mental model throughout, giving students a repeatable design pattern for agent systems.

4. **Alignment and safety integration:** Module 4 addresses the Alignment Problem practically (hallucination prevention, multi-agent loop management, API cost control) rather than treating ethics as an afterthought.

5. **Progressive project structure:** Three milestone projects move from workflow automation to autonomous decision-making to multi-agent collaboration, mirroring real-world complexity progression.

6. **JHU APL connection:** Faculty from the Johns Hopkins Applied Physics Laboratory bring defense and research-grade AI experience, distinguishing this from purely commercial/business-focused programs.

7. **Balanced accessibility:** More accessible than CMU (which requires working-level Python + LLM experience) while maintaining more technical rigor than UT Austin's no-code option.

8. **Reinforcement learning inclusion:** Few professional certificates cover RL in the context of agent design; JHU integrates it as a core module rather than an elective topic.

### Limitations
- Non-credit certificate (not equivalent to graduate coursework)
- Delivered through Great Learning partnership (not directly by JHU EP)
- Weekly unlock schedule limits self-paced learning
- Relatively new program with limited long-term outcome data
